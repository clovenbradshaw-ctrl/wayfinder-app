      SlowFree flow
      Estimated by timing WeGo buses from one stop to the next and comparing with each stretch's usual free-flow time. Time spent at stops is never counted. It only covers bus corridors; other roads show nothing, and a stretch needs 25 timed runs before it counts.

      Send someone a link that shows where you are on a map until it expires.
      Anyone with the link can see where you are until it expires (8 hours at most) or you stop. Positions are held only in memory on our server and are wiped when sharing ends. For someone you want to share with for good, use People below. In a browser it only sends while this page is open with the screen on; the Android app keeps sending with the screen off.

      PeopleNone
      Connect with someone you trust by trading a one-time code. Once connected, each of you can switch on sharing your live location with the other, for as long as you like, and switch it off any time. The server keeps only the connection, never where you were.
