# Wayfinder

Maps, turn-by-turn directions, bus times and live location sharing for Nashville. No Google services, no ads.

## Android app (works on GrapheneOS)

**[Download the Android app (APK)](https://github.com/clovenbradshaw-ctrl/wayfinder-app/releases/latest/download/Wayfinder.apk)**

Install steps, the file checksum and notes are on the [download page](https://clovenbradshaw-ctrl.github.io/wayfinder-app/download.html).

## Web app

[Open Wayfinder in your browser](https://clovenbradshaw-ctrl.github.io/wayfinder-app/) (installable as an app).

---
Static build of the Wayfinder web app for GitHub Pages. Map data from OpenStreetMap contributors (ODbL), vector tiles from Protomaps builds, icons from Phosphor (MIT), maps by Leaflet.
