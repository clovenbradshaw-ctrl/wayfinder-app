Install it

  1. Tap the button above. Your phone saves Wayfinder.apk.
  2. Open it from your downloads. Your phone asks to allow installing from this source (Vanadium, Chrome or Files). Allow it for this one install.
  3. Tap Install, then Open. Allow location when asked: choose While using the app and Precise.
GrapheneOS: Settings → Apps → (your browser or Files) → Install unknown apps → allow. Turn it off again afterwards if you like. The app has no Google code in it.

Phones: arm64 and 32-bit ARM (almost every Android phone since 2014). Needs Android 8 or newer. Updates install over the old version when signed with the same key; if your phone refuses an update, uninstall once and install again.
Spoken directions need a text-to-speech engine. GrapheneOS ships none: install RHVoice or eSpeak NG from F-Droid, then pick it in Settings → System → Languages → Text-to-speech output.

Prefer no install? Open the web app in your browser and use “Install app”. The Android app adds navigation that keeps going with the screen off.
